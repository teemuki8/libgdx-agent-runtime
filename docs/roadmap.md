# Roadmap

## V1

- Explicit entity inspection
- Completed frame snapshots
- Automatic structural diffs without inferred causality
- Structured runtime events
- Semantic decision traces
- Typed Java, protocol, and MCP queries

## Potential V2

- Scene2D correlation with `libgdx-ui-harness`
- Ashley adapter
- Artemis adapter
- Pause and frame stepping
- Conditional capture
- Richer metrics
- Trace archive viewer

These are possibilities, not commitments.

## Research

- Deterministic replay
- Mutation attribution
- Java agent or bytecode instrumentation
- Source-location capture
- Rollback support
- Engine-level architecture
- Agent-authored executable assertions

Research items have no delivery commitment and may be rejected if they conflict with explicit,
bounded, third-party-library design.
