# 0.1.0 release candidate

The first candidate proves one complete explicit inspection workflow through Java, strict JSON, and
eight stdio MCP tools. It qualifies JDK 25 and LWJGL3 desktop on Linux/Xvfb.

Known limits: process-local MCP hosting, in-memory retention, one capture thread, no replay, no
remote transport, no ECS adapter, and no mobile/web qualification. libGDX 1.14.2's LWJGL 3.3.3
backend emits upstream JDK 25 native-access compatibility warnings during the otherwise passing
LWJGL3 smoke test.
Optional simulation control remains application-owned: applications explicitly register
pause/resume/tick callbacks and named conditions, keep servicing their command queue while paused,
and receive bounded completed-frame evidence. The runtime creates no game loop or scheduler.
Optional checkpoints likewise retain only bounded descriptors and opaque application handles.
Create, restore, and disposal callbacks run under application ownership; successful restore produces
one new completed epoch baseline, while payloads never cross protocol or MCP.
Optional runtime/UI correlation uses explicit application-provided semantic bindings and frame
mappings with bounded retention. It does not inspect UI objects or infer relationships.

The Maven publications can be assembled locally. The protected GitHub `maven-central` environment
stages signed artifacts for manual review in the Central Publisher Portal after maintainer signing
and Portal credentials are configured. No publication to Maven Central is performed automatically.
Publication archives embed the Apache-2.0 license and project notice, and the generated POMs identify
the maintainer and source repository.
