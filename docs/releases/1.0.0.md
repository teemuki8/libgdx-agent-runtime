# 1.0.0

The first production-supported release establishes the stable 1.x Java and protocol contracts for
bounded semantic inspection and application-owned control of a live libGDX game.

## Published artifacts

All artifacts require Java 25 and use group `io.github.teemuki8`:

- `agent-runtime-core`
- `agent-runtime-libgdx`
- `agent-runtime-protocol`
- `agent-runtime-mcp`

`runtime-fixtures` is qualification code and is not published.

## Included contract

- JDK-only immutable core state, baseline/frame capture, stable diffs, events, decisions, queries,
  execution epochs, explicit attribution, typed actions, and declarative assertions.
- Optional application-owned scenarios, pause/resume/exact-tick control, named waits, registered
  input injection, opaque checkpoints, runtime/UI correlation, bounded recording, and repeated-run
  determinism comparison.
- Exact closed JSON protocol versions 1.0 through 1.13. Protocol 1.0 retains its original eight
  read-only commands; later versions opt into bounded capability and control extensions.
- Local same-JVM stdio MCP hosting with eight base tools and only those optional tools backed by
  concrete registered capabilities.
- A deterministic fixture that exercises the public Java API, strict JSON, real stdio MCP, the
  application/render-thread dispatch boundary, and a real LWJGL3 lifecycle under Linux/Xvfb.

The stable compatibility and support rules are recorded in
[ADR 0011](../adr/0011-stable-1x-compatibility.md) and [SECURITY.md](../../SECURITY.md).

## Qualified platforms and dependencies

The release is compiled and tested with JDK 25 on Linux, Windows, and macOS. The real native fixture
qualifies LWJGL3 desktop on Linux under Xvfb; Android, iOS, and web are not release claims.

The reviewed direct dependency set is libGDX 1.14.2, Jackson 2.22.1, Java MCP SDK 2.0.0, and JUnit
6.1.2. The MCP artifact intentionally resolves both Jackson 2 for this project's strict protocol and
the SDK's package-distinct Jackson 3 stack. The native libGDX/LWJGL stack can emit upstream JDK 25
native-access warnings while the isolated lifecycle fixture succeeds.

## Upgrade from 0.1.0

Version 0.1.0 was a preview and is not a compatibility baseline. Consumers should update every
runtime module they use to 1.0.0, select the exact protocol version they implement, and recompile.
No separate JVM can inspect a running game: MCP must remain in an application-owned same-JVM
development launcher.

## Release verification

The candidate is accepted only when this isolated Linux gate succeeds and the same commit passes CI
on Linux, Windows, and macOS:

```bash
xvfb-run -a ./gradlew -PreleaseVersion=1.0.0 \
  clean check javadoc generatePomFileForMavenJavaPublication \
  --warning-mode=fail
```

Tagging, signing, Central staging, Portal inspection, and immutable publication are separate
maintainer-authorized steps described in the release guide.
