# 0.1.0 release candidate

The first candidate proves one complete explicit inspection workflow through Java, strict JSON, and
eight stdio MCP tools. It qualifies JDK 25 and LWJGL3 desktop on Linux/Xvfb.

Known limits: process-local MCP hosting, in-memory retention, one capture thread, no replay, no
remote transport, no ECS adapter, and no mobile/web qualification. libGDX 1.14.2's LWJGL 3.3.3
backend emits upstream JDK 25 native-access compatibility warnings during the otherwise passing
LWJGL3 smoke test.

The Maven publications can be assembled locally, but release signing and Maven Central upload
remain intentionally unqualified until maintainer signing credentials and Central credentials are
configured. No publication is performed automatically.
